📌 Spring REST Module (Important Module in Spring Framework):

> > Hello Guys, In this video, we will discuss the Spring REST Module.

> > Spring REST is an important module used to develop APIs and Distributed Applications.

> > REST means (Representational State Transfer).

> > As a Java Developer, daily we need to work with the Spring REST Module.

> > Let me explain with a real-time example.

> > PHONEPE EXAMPLE:

>> For suppose, if my friend asks me to send ₹5000, I will open my PhonePe app.

>> I am using HDFC Bank and my friend is using SBI Bank. 
>> PhonePe first communicates with HDFC Bank to deduct the amount. 
>> Then, HDFC sends the response back to PhonePe, 
>> And next, PhonePe communicates with SBI Bank to credit the amount.

> > Here, one app is communicating with another app.

> > These types of applications are called Distributed Applications.
